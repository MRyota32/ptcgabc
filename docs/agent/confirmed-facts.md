## F-4. 偽陽性の検出と撤回【writeupの核心事件】

- **旧主張**：「瀕死ロジックが対v2勝率を+13.4pt悪化させる因果（37.9%→51.3%）」
- **機序**：小N（N=240 + 別セッションN=300）で検出した外れ値（37.9%）を、そのまま実験動機かつ比較ベースラインに流用。=「勝者の呪い」
- **決着実験**（事前登録・同一セッション・N=1,000×2）：v4 47.0% [43.9, 50.1] / ablate 50.4% [47.3, 53.5] / 差 +3.4% [-1.0, +7.8]（**0跨ぎ → 効果なし**）
- **帰結**：瀕死ロジックは「有害」でなく「ほぼ不活性（dead weight）」
- 陰性対照較正：v2同士 N=500×5試行で50%逸脱 0/5 → 測定器は無バイアス・偽検出≈5%
