# 用語集

## ゲーム・エンジン用語

| 用語 | 意味 |
|------|------|
| **Mega Lucario ex** | 使用デッキの主軸。倒されると3プライズ（通常は1〜2）。略称「MLex」 |
| **Aura Jab** | ワザ1。1Fエネ・130ダメ・捨て場から基本Fエネ3枚ベンチ配布 |
| **Mega Brave** | ワザ2。2Fエネ・270ダメ・使用後次ターン使用不可 |
| **crustle（イワパレス）** | 特性「しんぴのいしやど」：exポケモンからのダメージを受けない。Lucario exを構造的に詰める |
| **幻影ジャック** | Zoroarkのワザ。60 × 相手のex/V数ダメ。Lucario ex（1体で60/120）に刺さる |
| **errorType=4** | battle_start でエンジン非対応カードを含むデッキを弾く。エラーコード。`check_deck_legal.py` で事前確認 |
| **3プライズ** | Mega exが倒されたとき相手に渡るプライズの枚数（通常の3倍） |

## 測定・統計用語

| 用語 | 意味 |
|------|------|
| **ミラー** | 同一デッキ同士の対戦。版差の純粋な比較に使う |
| **座席固定** | 先攻/後攻を固定した比較（例：v5後攻固定 vs v2先攻固定）。先攻有利の影響を分離する |
| **balanced** | 先攻後攻を毎試合交互にして均等化した測定。通常の勝率比較に使う |
| **発火率** | 特定のコード分岐（if文）が実際に実行される試合の割合。高くても勝率影響ゼロがありうる |
| **Wilson CI** | 勝率の信頼区間の計算式。小サンプルでも安定した区間を与える |
| **2標本差CI** | 2アームの勝率差の信頼区間。0を含まなければ有意差あり |
| **パリティ** | 有意差なし。「等価」ではなく「検出限界（±6〜7pt）以内の差」 |
| **昇格ゲート** | 新版を採用するための事前登録された判定基準 |
| **事前登録** | 実験前に「主比較・N・判定基準」を宣言する行為。結果を見てから比較を選ぶバイアスを防ぐ |

## 落とし穴名称

| 名称 | 意味 |
|------|------|
| **勝者の呪い (winner's curse)** | 異常に悪い1観測をきっかけに実験を設計し、その値をベースラインにする選択バイアス。平均回帰で「効果」が必ず出る |
| **Goodhartリスク** | 自作相手への過適合が、ラダー（本物のフィールド）に転移しない現象 |
| **dead code** | 発火率0%のコード分岐。実際には一度も実行されない |
| **ラダーとローカルの逆転** | ローカルで勝率が高いデッキがラダーEloで劣位になる現象。外的妥当性の問題 |

## ファイル・ディレクトリ

| 名称 | 意味 |
|------|------|
| **cabt_harness.py** | 評価ハーネスのメインスクリプト。ハーネス環境（ローカルに不在）に存在 |
| **check_deck_legal.py** | `battle_start(deck, deck)` でデッキ合法性を確認するスクリプト |
| **battle_start** | エンジンAPIの対戦開始関数。`errorPlayer==-1` なら合法 |
| **cg_tmp/** → **engine/** | エンジン本体。libcg.so（Linux）/ cg.dll（Windows）はgitignore |
| **AGENTS.md** | 薄いルーター：ハードルール・ルーティング表・docs一覧 |
